# Screen probe

Installable web app that reports what a browser sees of the device: CSS viewport, devicePixelRatio, safe-area insets,
foldable viewport segments and posture, pointer type, display mode, WebGL2. Updates live on rotate, fold and resize.
Nothing is sent anywhere.

Live: https://chazmaniandinkle.github.io/screen-probe/ — on Android Chrome use "Add to home screen" / "Install app";
it launches fullscreen, so the numbers are the ones a fullscreen game gets.

Built to calibrate MonEngine's touch layouts on a foldable. MIT.
